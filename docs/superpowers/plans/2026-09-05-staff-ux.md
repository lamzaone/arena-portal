# Staff UI and interaction polish

**Goal:** Improve Staff readability, task navigation, responsive layouts, theme consistency, and opening/closing feedback while preserving the ARENA identity and existing authorization.

**Architecture:** Keep the existing server pages and action endpoints. Improve their shared Staff navigation/header and semantic styling; use reusable client components for confirmation dialogs and notification lifecycles.

**Tech stack:** Next.js 16, React 19, CSS, Lucide. No production dependency additions.

## Requirements

- Preserve the current dark rose default, BETA TESTER, and TAP GOD themes and player-owned theme boundaries.
- Keep existing role filtering, form submission payloads, validation, action endpoints, and CSRF fields.
- Improve desktop hierarchy and mobile navigation without hiding actions.
- Animate entrance and exit; honor reduced motion, keyboard focus, Escape dismissal, and native form validation.
- Work locally; do not deploy or mutate production data.
